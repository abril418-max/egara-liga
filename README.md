# Club Egara · Penya Arlequinada

Web de consulta del equipo: clasificación, calendario, ranking, rivales, jornadas, jugadores, parejas y temporada 25/26.

- `index.html`: la web publicada (se genera automáticamente, no editar a mano).
- `scripts/app.html`: la aplicación original.
- `scripts/build.py`: genera `index.html` a partir de los datos descargados de la aplicación en `data/` (no se sube al repositorio).
